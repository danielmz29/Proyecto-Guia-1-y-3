What is web development?

Web development is the process of building and maintaining websites and web applications. It combines three core technologies: HTML to structure the content, CSS to style it, and JavaScript to make it interactive.

Learn more in the official documentation: MDN Web Docs - Learn Web Development.

My development toolkit

  • Code editor

    Visual Studio Code is where I write and organize my code.

  • Browser

    Chrome renders the page so I can check how it looks and behaves.

  • Local server

    Live Server reloads the page automatically each time I save.

  • Developer tools

    The F12 panel helps me inspect elements and find errors.
