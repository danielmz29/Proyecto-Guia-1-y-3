# Guía 4 – Desarrollo de una interfaz web responsiva

**SIGDocs Lab**: sistema de gestión documental para laboratorios.

- **Estudiante:** Daniel Felipe Mojica Sánchez
- **Asignatura:** Ingeniería Web – Universidad Manuela Beltrán
- **Docente:** Juan José Osorio

## Tecnologías
- HTML5 semántico (`section`, `aside`, `nav`, `header`, `main`, `article`, `form`, `footer`)
- CSS3: CSS Grid, Flexbox y Media Queries (1100 px, 900 px y 640 px)
- JavaScript (sin librerías)

## Estructura
```
Guia-4/
├── index.html   Estructura de la interfaz
├── css/         Hoja de estilos
├── js/          Interacción (sesión, menú móvil, filtros, carga y exportación)
├── img/         Logotipo, isotipo e íconos
└── docs/        Documentación técnica en PDF
```

## Nota
Esta carpeta contiene solo el frontend de la aplicación. Los datos se obtienen de un backend
privado, así que al abrir `index.html` localmente se ve la pantalla de inicio de sesión; las
vistas internas se muestran en las evidencias de la documentación y en el video.
