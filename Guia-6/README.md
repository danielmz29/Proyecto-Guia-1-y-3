# Guía 6 – Proyecto integrador de Ingeniería Web I

**SIGDocs Lab**: sistema de gestión documental para laboratorios.

- **Estudiante:** Daniel Felipe Mojica Sánchez
- **Asignatura:** Ingeniería Web – Universidad Manuela Beltrán
- **Docente:** Juan José Osorio

## Propuesta
- **Problemática:** los laboratorios manejan sus documentos de calidad en carpetas o Excel, con versiones desactualizadas y vigencias sin control.
- **Público objetivo:** laboratorios clínicos (líderes de calidad, directores técnicos y personal).
- **Solución:** aplicación web responsiva con panel de estado, procesos y subprocesos, carga documental, listado maestro con filtros y exportación, usuarios y roles.

## Tecnologías
HTML5 semántico · CSS3 (Grid, Flexbox, Media Queries, unidades relativas) · JavaScript

## Estructura
```
Guia-6/
├── index.html   Estructura de la interfaz
├── css/         Hoja de estilos
├── js/          Interacción (sesión, menú móvil, filtros, carga y exportación)
├── img/         Logotipo, isotipo e íconos
└── docs/        Documentación del proyecto en PDF
```

## Nota
Esta carpeta contiene el frontend de la aplicación. Los datos se obtienen de un backend privado,
así que al abrir `index.html` localmente se ve la pantalla de inicio de sesión; las vistas
internas se muestran en las evidencias de la documentación.
